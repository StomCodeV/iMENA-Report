# iMENA Report

iMENA Report is an independent report formatting and consistency tool for student teachers. It does not generate report content, does not write on behalf of students, and is not affiliated with MINEDUC, NESA, REB, TTC Muhanga, or any host school. All report content is authored by the student. The tool checks internal consistency, enforces structural format, and produces a formatted PDF. Academic responsibility rests with the student and their mentor.
